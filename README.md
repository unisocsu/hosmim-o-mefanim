## הורדה והפעלה

### אפשרות 1 — EXE לווינדוס (הכי פשוט)
הורידו את `חוסמים את הציר.exe` מ**[עמוד המהדורות](../../releases/latest)**,
לחצו פעמיים, שחקו.

> **הערה על SmartScreen:** הקובץ אינו חתום בתעודת קוד מסחרית, ולכן ווינדוס
> עשוי להציג "Windows protected your PC" — לוחצים **More info → Run anyway**.
> זה צפוי בכל תוכנה ביתית לא-חתומה.

### אפשרות 2 — ZIP לדפדפן (634KB)
מורידים את ה-ZIP מהמהדורה, **מחלצים** (לא לשחק מתוך ה-ZIP!), ופותחים את
`להפעלה.html`. עובד בכל דפדפן, גם בלי אינטרנט.

## איך משחקים

**כמפגינים:** גוררים עכבר לבחירת מפגינים, קליק על הכביש שולח אותם לחסום
(ירוק = בטוח, אדום = רכב מתקרב!). קליק על רכב עומד — נצמדים אליו והשוטרים
מתקשים לפנות. שכיבה על הכביש מכפילה את זמן הפינוי.

**כמשטרה:** קונים כוחות מהתקציב, גוררים מלבן לבחירת שוטרים וקליק לפקודה.
המטרה: לפנות את הציר לפני שהוא אבוד.

### מקלדת
`רווח`/`P` הפסקה · `Tab` מיני-מפה · `חיצים`/`WASD` מצלמה · `Q`/`E` סיבוב ·
`+`/`-` זום · `1`–`7` כלים · `L` שכיבה · `K` קימה · `M` השתקה · `F11` מסך מלא

## פיתוח

הכל בקובץ אחד — `index.html` (HTML + CSS + JS, ~3,900 שורות, three.js r128
מקומי). אין בנדלר, אין `npm install` למשחק עצמו.

```bash
python -m http.server 8765
```

לבניית ה-EXE: התצורה ב-`desktop/` (Electron + electron-builder).
**חשוב:** לבנות מתיקייה בנתיב ASCII — electron-builder נשבר על נתיבים עבריים.

`CLAUDE.md` מכיל מפת ארכיטקטורה מלאה עם עוגני חיפוש לכל תת-מערכת.
